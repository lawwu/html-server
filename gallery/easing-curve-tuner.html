Rules of thumb: things entering should decelerate (fast start, gentle stop: ease-out); things leaving can accelerate away (ease-in); things moving within the screen use ease-in-out. Small UI elements want 150–250 ms; large surfaces 300–450 ms.

Curves are evaluated with the same cubic-bezier model CSS uses (x solved by Newton's method, then y). Copying uses the clipboard if the page is allowed to; otherwise the text is selected for you.
