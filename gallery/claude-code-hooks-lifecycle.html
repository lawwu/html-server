Claude Code hooks — when each one fires

Hooks are shell commands, HTTP endpoints, MCP tools, prompts or agents that you define and Claude Code runs automatically at set points in a session. Pick what you want a hook to do to see where it can; step through one turn for the order; select any event for its matcher, input and what it can return.

Any time

Not tied to a step in the turn: each fires when its trigger happens.

  • Claude Code needs you: a prompt has waited ~6 s, Claude went idle ~60 s ago, and more

  • A settings or skill file changes

  • The working directory changes, e.g. Claude runs cd

  • A watched file changes on disk

  • You add a directory with /add-dir

  • A nested CLAUDE.md or path-scoped rule loads

  • The model changes: before a switch you ask for, after any change

    →

  • A worktree is created, or one your hook made is removed

Wire one up

The docs’ own example: a PreToolUse hook that refuses rm -rf. A hook nests three levels deep in a settings file.

  1. 1Hook event: when it runs. Here, before every tool call.
  2. 2Matcher group: which occurrences. Only Bash calls; the handler’s if narrows that to rm commands, so the script never starts for npm test.
  3. 3Hook handler: what runs. A command here; also http, mcp_tool, prompt or agent.
stdin, as JSON
{ "hook_event_name": "PreToolUse",
  "tool_name": "Bash",
  "tool_input": { "command": "rm -rf /tmp/build" }, … }
stdout, exit 0
{
  "hookSpecificOutput": {
    "hookEventName": "PreToolUse",
    "permissionDecision": "deny",
    "permissionDecisionReason": "Destructive command blocked by hook"
  }
}

Claude Code blocks the call and shows Claude the reason.

exit 0

Success. Claude Code applies any JSON on stdout. Silence isn’t approval: on PreToolUse the normal permission flow still runs.

exit 2

Blocks the action on events that can block; stderr is the reason. Elsewhere it is shown or ignored.

any other

Without valid JSON on stdout, a non-blocking error, exit 1 included: the action goes ahead. Set "onFailure": "block" to fail closed instead.
