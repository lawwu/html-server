Architecture · artifact server

One process, one SQLite file, every page sandboxed

The artifact server stores single-file HTML pages, keeps every upload as an immutable version, searches them with full-text search, and renders each page in an opaque-origin sandbox. Pick a request below to trace its path.

Writes go through one table

Every mutation asks transition(state, event) for the next lifecycle state. A pair missing from the table is a 409 that lists the allowed events, so a trashed page can't take a new version and an active one can't be purged by accident.

Versions are immutable

Each upload appends a row with its sha256 and an optional note. "Make this version current" appends a copy rather than rewriting history; only purge removes rows.

Search sees only the latest

The FTS5 index holds the title and visible text (script and style stripped) of each page's latest version. Every word must match as a prefix or as a close misspelling found through the vocabulary table.

The URL is the file name

curl -T trip-plan.html serves at /trip-plan.html. Names are global and first-come; api, v, review are reserved. Private pages are reached only through a random /v/<id> share link.
