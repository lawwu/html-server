Claude Code permission prompts — a working prototype

A scripted Claude Code session in a fictional repo. Claude proposes an edit, a shell command and a web fetch, and you answer each permission prompt the way the Claude Code docs describe: allow once, save a rule, decline with a comment, cycle permission modes, or plan first.

Simulated session

~/code/slugsmithsimulated

Try these 0 of 5

  • Allow once. Choose Yes on any prompt. The next prompt still asks.

  • Don’t ask again. Option 2 on the npm test or fetch prompt saves a rule below, and the next test run doesn’t ask.

  • Decline with feedback. On the edit prompt, move to No, press Tab, type a note and press Enter. Claude revises.

  • Cycle modes. At the input, press Shift+Tab and watch the mode under it change.

  • Plan first. Cycle to plan mode before you send. Claude plans, and edits wait until you approve.

      Keys
      

      

      Enter
      Send the prompt, or choose the highlighted option
      

      ↑ ↓
      Move between options; 1–4 choose directly
      

      Tab
      On Yes or No: open a comment field, and again to close it
      

      Shift+Tab
      At the input: cycle permission modes. On an edit prompt: choose option 2
      

      Esc
      On a prompt: decline, the same as No without a comment. While Claude works: interrupt
      

      Ctrl+G
      On the plan prompt: open the plan in your editor (CLI only)
      

      

      The mouse works too: click an option, use + comment for a note, and the shift+tab button under the input to cycle modes.
