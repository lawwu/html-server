Claude Code— a pocket reference

The keys, commands and flags worth keeping in your head, grouped by what you are doing. In Claude Code itself, press ? on an empty prompt for the shortcut panel, or type / to see the commands available to you.

>

/ to filter · Esc to clear

At the prompt

/ to start
Command or skill. Keep typing to narrow the list.
! to start
Shell mode: you run the command, its output joins the conversation and Claude responds.
@
Mention a file path, with autocomplete.
? on an empty prompt
Show the shortcut panel.
\+Enter
New line, in any terminal.
Shift+Enter
New line in iTerm2, WezTerm, Ghostty, Kitty, Warp, Apple Terminal and Windows Terminal. /terminal-setup adds it to VS Code, Cursor, Devin Desktop, Alacritty and Zed.
Tab
Accept the selected autocomplete suggestion.
Ctrl+_
Undo your last edit to the prompt.

Hold Ctrl

Start & resume

Opening a terminal, or coming back to one

claude
Start an interactive session.
claude "query"
Start one with an opening prompt.
claude -c --continue
Continue the most recent conversation in this directory.
claude -r "<session>" --resume
Resume a session by ID or name. Leave the name off to pick from a list.
--fork-session
With -c or -r: carry on under a new session ID instead of reusing the original.
claude -n "name" --name
Name the session. The name shows in /resume and the terminal title, and claude -r name finds it.
claude --from-pr 123
Pick from the sessions linked to a pull request, by number or URL.
claude -w [name] --worktree
Start in an isolated git worktree under .claude/worktrees/.
/resume [session] /continue
Switch to an earlier conversation, or open the picker.
/branch [name]
Branch the conversation here to try another direction. The original stays in /resume.
claude agents
Open agent view to watch and dispatch background sessions.
/exit /quit
Leave. In an attached background session, it detaches and the session keeps running.

Steer a session

While Claude is working

Esc
Stop Claude mid-turn to redirect it. The work so far is kept.
Esc Esc
On an empty prompt, open the rewind menu. With text, clear the draft; Up brings it back.
Enter while Claude works
Queue a message instead of interrupting. Claude gets it when the running tool calls finish, or when the turn ends.
Ctrl+Enter or Ctrl+X Ctrl+S
Send queued messages right away. The chord works in any terminal. 2.1.275+
Ctrl+C
Interrupt. With nothing running, clear the prompt; a second press exits.
Ctrl+B
Move running Bash commands and agents to the background. In tmux, press it twice.
/tasks /bashes
See and manage this session’s background work.
/background [prompt] /bg
Detach the whole session as a background agent and free the terminal.
Option+P or Alt+P
Switch model without clearing your prompt.
/model [model]
Switch model and keep it as your default. In the picker, S on a row switches this session only.
/effort [level]
Set effort: low to xhigh, max, or auto.
Option+O or Alt+O
Toggle fast mode. /fast does the same.
Ctrl+O
Toggle the transcript viewer: tool calls in detail, with timestamps.
/diff
Review uncommitted changes, Claude’s edits included.
/rewind /undo /checkpoint
Roll code, conversation or both back to an earlier point.
/copy [N]
Copy the last response, or the Nth-latest, to the clipboard.

Manage context

When the conversation gets long

/context
See what is filling the context window, with suggestions for trimming it.
/compact [instructions]
Summarize the conversation to free space. Add instructions to focus the summary.
/clear [name] /reset /new
Start a new conversation with empty context. The old one stays in /resume.
/btw [question]
Ask a side question. Neither it nor the answer joins the conversation history.
/autocompact [auto|<tokens>]
Set how full the window gets before Claude Code compacts on its own, such as 500k.
/memory
Edit CLAUDE.md files; turn auto memory on or off.
/init
Write a starter CLAUDE.md for the project.
/add-dir <path>
Give Claude file access to another directory. At launch: --add-dir.
/usage /cost /stats
Session cost, plan usage limits and activity.
/export [filename]
Export the conversation as plain text, to a file or the clipboard.

Permissions

What runs without asking

/plan [description]
Enter plan mode, optionally with the task: /plan fix the auth bug.
/permissions /allowed-tools
View and edit allow, ask and deny rules.
--permission-mode <mode>
Start in default (manual), acceptEdits, plan, auto, dontAsk or bypassPermissions.
--allowedTools "Bash(git log *)" "Read"
Let matching tool calls run without a prompt.
--disallowedTools "Edit"
Deny rules. A bare tool name removes the tool; Bash(rm *) denies only matching calls.
--tools "Bash,Edit,Read"
Limit which built-in tools Claude has. "" turns them all off.
--dangerously-skip-permissions
Skip permission prompts, as bypassPermissions. Meant for isolated containers and VMs.
--allow-dangerously-skip-permissions
Put bypassPermissions on the Shift+Tab track without starting in it.
/sandbox
Turn the sandbox for Claude’s shell commands on or off, where supported.
Tab on a permission prompt
Add a comment to your Yes or No.
/fewer-permission-prompts
Find common read-only calls in your transcripts and allowlist them.

Configure

Settings, servers, plugins, and when something breaks

/config [key=value] /settings
Open settings, or set one directly: /config theme=dark.
/status
Version, model, account and connectivity.
/doctor /checkup
Diagnose install, settings and CLAUDE.md problems; Claude applies fixes after you confirm.
/mcp
Manage MCP server connections and sign-ins.
/plugin
Browse, install, enable or disable plugins.
/skills
List your skills; T sorts them by token count.
/keybindings
Open your keybindings file to change shortcuts.
/statusline
Set up the status line: describe what you want, or run it bare to build one from your shell prompt.
/theme
Color theme, with auto, light, dark, colorblind-friendly and ANSI options.
--model <model>
Model for this session: sonnet, opus, haiku, fable or a full name.
--settings <file-or-json>
Override settings for this session only.
--safe-mode
Start with every customization off, to see whether one is the problem.
claude update
Update to the latest version.
claude doctor
Read-only install and settings diagnostics, without starting a session.

Scripting with -p

No one at the keyboard

claude -p "query" --print
Answer, print the response, exit.
cat logs.txt | claude -p "explain"
Pipe content in.
claude -c -p "query"
Continue the most recent conversation non-interactively, earlier -p runs included.
--output-format text|json|stream-json
Choose the output format.
--json-schema '{…}'
Get validated JSON that matches your schema once the work is done.
--max-turns 3
Cap the number of agentic turns.
--max-budget-usd 5.00
Stop once estimated API spend reaches the cap.
--allowedTools "Bash(npm test)" or --permission-mode auto
-p runs deny any call that needs approval. List what may run, or let auto mode’s classifier review each call. 2.1.302+
--bare
Skip hooks, skills, plugins, MCP servers, auto memory and CLAUDE.md so scripted calls start faster.
--append-system-prompt "…"
Add instructions to the default system prompt.
--system-prompt "…"
Replace the default system prompt entirely.
--include-partial-messages
Stream partial events too. Needs --output-format stream-json.
--no-session-persistence
Don’t save the session to disk; it can’t be resumed.
claude setup-token
Generate a long-lived OAuth token for CI and scripts. Needs a Claude subscription.

Keys can differ by platform and terminal. On macOS, Option shortcuts such as Option+P need Option set as Meta in your terminal. In commands, <angle> marks a required argument and [square] an optional one.
