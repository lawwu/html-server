Four datasets, one set of numbers

In 1973 the statistician Francis Anscombe published four small datasets, eleven points each, built so that their usual summary statistics agree to two or three decimal places. His point was blunt: a regression printout is not a substitute for a graph. This notebook walks through the quartet the way you would with any new data — summarize, plot, fit, then check the fit.

2 · Summarize

In [2]:
summary = {k: describe(x, y) for k, (x, y) in quartet.items()}

Highlighted rows agree across all four sets to within a unit in the last printed digit. Same means, same variances, same correlation, same least-squares line y ≈ 3.00 + 0.500x. If this table were all you saw, you would conclude the four datasets describe the same relationship.

3 · Plot

In [3]:
for k, (x, y) in quartet.items():
    scatter(x, y); abline(fit(x, y))   # dashed line = least-squares fit
Hover or tap a point.

The pictures disagree completely. I is what the table promised: a noisy linear trend. II is a smooth curve — a parabola fit by a straight line. III is a perfect line except for one point that drags the slope upward. IV has no relationship at all: ten points share one x value, and a single far point manufactures the entire slope. Switch to the residual view and the problems become impossible to miss — structure where there should be noise, and one residual towering over the rest.

4 · Influence check

In [4]:
# refit each set without its single most-influential point (largest Cook's distance)
for k, (x, y) in quartet.items(): print(k, fit(x, y), fit(drop_max_cooks(x, y)))
Takeaway
  1. Summary statistics compress; they also hide. Identical moments and fits can come from linear, curved, outlier-driven and degenerate data.
  2. Plot before you model, and plot residuals after. A residual plot turns "the fit looks fine" into a checkable claim.
  3. Check influence. In III and IV one point controls the answer; a robust refit or a leave-one-out check exposes it in a line of code.
